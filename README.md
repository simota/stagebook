# Stagebook

ライブハウスに出るバンドが、1公演分の書類をまとめて作って印刷するための Web アプリです。ブラウザだけで動き、サーバーやアカウントはありません。

## 作れる帳票

| 帳票 | 用紙 | 内容 |
|---|---|---|
| A-1 演者用セットリスト | A4 縦 | ステージ上で見る大きな文字のセットリスト。文字の大きさは曲数に合わせて自動で決まる |
| A-2 スタッフ用セットリスト | A4 縦 | 曲ごとの開始時刻・尺・BPM・キー・つなぎ・注釈 |
| B ステージ図 | A4 横 | ステージ図・チャンネル表・機材表・返しの要望 |
| C 音響照明 | A4 横 | 曲ごとの照明の色・雰囲気・きっかけと音響の指示 |
| D 取り置き | A4 縦 | 受付に渡す取り置きリスト（よみがなの五十音順） |
| E タイムテーブル | A4 縦 | 入りから撤収までの当日の流れ |

各帳票に載せる項目は「表示する項目」で切り替えられます。帳票のフォントは、端末のフォントと5種類の Web フォントから選べます。

## 使い方

1. 上部の「新規」で公演を作る（「サンプル」で記入例を開ける）
2. 左のタブで、基本情報・メンバー・セットリスト・ステージ図などを入力する。セットリストは「テキスト」タブでまとめて書くこともできる
3. 右のプレビューで帳票を確かめ、「このシートを印刷」か「全シート印刷」で印刷する（「全シート印刷」は Chrome 系のブラウザのみ）

### データの保存先と受け渡し

- 入力した内容は、そのブラウザの中（localStorage）にだけ自動で保存されます。ほかの端末やブラウザとは同期しません
- 「JSON書き出し」で1公演を、「全公演をバックアップ」で全公演をファイルに保存できます。どちらも「JSON読み込み」で戻せます
- 「共有リンクをコピー」で、連絡先を含む公演の内容を URL に入れて渡せます。取り置きリスト（予約者の名前）は入りません。受け取った人のブラウザには新しい公演として保存されます

## 開発

必要なもの: Node.js 22、テストの e2e には Google Chrome

```sh
npm ci
npm run dev        # 開発サーバー
npm run build      # 型チェックとビルド（dist/ に出力）
npm run preview    # ビルドしたものを確認
```

### テスト

```sh
npm test           # ユニットテスト（Vitest）
npm run typecheck  # 型チェック
npm run e2e        # e2e テスト（Playwright。ビルドしてから 127.0.0.1:4173 で動かす）
npm run measure    # 品質の計測（docs/quality/sqi.md の数値の再現用）
```

e2e は、ローカルのポートを開けない環境（サンドボックスなど）では動きません。

### 公開

`main` に push すると、GitHub Actions がテストとビルドを行い、GitHub Pages に公開します（`.github/workflows/deploy.yml`）。

### 資料

- `docs/plans/architecture.md`: 構成の決定とその理由
- `docs/format-research.md`: 帳票の形の調査
- `docs/quality/`: 品質の評価の記録
