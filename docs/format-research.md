# 出力フォーマット調査と決定案

対象: A4印刷用の3種類の帳票（セットリスト / 機材表・ステージ図 / 音響・照明シート）。frontendのみで作る（保存はブラウザ内とJSONファイル、出力は印刷用CSSとSVG）。

## 1. 調査で分かった現場の慣習

### 国内ライブハウス
- セットリストは「メンバー、曲順、立ち位置、照明、音響の指示」をまとめて事前提出するもの。PA・照明スタッフが進行に使う。[島村楽器](https://www.shimamura.co.jp/update/?p=4569)
- 曲ごとに書く項目: カバーならアーティスト名、オリジナルなら「オリジナル」、BPM（求められることがある）、SE・MCの有無、エンディング。[サウンドハウス](https://www.soundhouse.co.jp/contents/column/index?post=4545)
- 照明・音響欄には「コーラスの有無」「ギターソロの担当（ギターが2本なら特に）」を書くと役立つ。同上
- 照明の要望は機材の指定ではなく雰囲気を言葉で書く（例:「夕方から夜にかけて」「光と影を意識してシンプルに」）。音響は曲ごとの欄と、返し・外音の全般的な要望に分かれる。[Bunkamura記入見本](https://www.bunkamura.or.jp/bunka/event^info/Amateur_Ongakusai/Amateur2016/5B_kinyuu_mihon.pdf)
- 曲順表はサウンドチェックまでにPAと照明に渡すのが一般的。

### 海外のテクニカルライダー
- 基本は3点: Stage Plot（ステージ図）、Input / Channel List（チャンネル表）、Backline / Equipment List（機材リスト）。[MusicNSW](https://www.musicnsw.com/resources/tech-rider-stage-plot-template)、[Robot Needs Home](https://www.robotneedshome.com/resource/how-to-put-together-a-first-tech-spec-the-stage-plot-and-channel-list)
- ステージ図に描くチャンネル番号は、チャンネル表の番号と一致させる。[Daysheets](https://www.daysheets.com/blog/stage-plot-the-complete-guide-for-tour-managers)
- ステージ図とチャンネル表を1枚にまとめた「One-Page Tech Rider」も定番。[ProSoundWeb](https://www.prosoundweb.com/?p=44835)
- 照明のキューシートは1キュー1行で、列は「キュー番号 / 曲 / きっかけ(go when) / 内容 / 備考」。[St. Olaf 実例](https://www.stolaf.edu/people/bjorklun/RnR%202024/LightingDesign/CueSheet%20RnR2024.pdf)、[StageAgent](https://stageagent.com/templates/lighting-cue-sheet)
- ライトプロット（灯体の配置図）は「何が設置されているか」、キューシートは「本番でどう変化させるか」を示す別の書類。[SHEHDS](https://shehds.com/blogs/news/what-is-lighting-cue-sheet)

### 設計に効く結論
1. 1つの公演データから「演者用」と「スタッフ用」の帳票をそれぞれ作る。演者は大きな曲名だけ、スタッフは詳細な表が欲しい。
2. 照明は灯体図ではなく「曲ごとの色と雰囲気、きっかけ」のシートにする。国内の記入見本が雰囲気を言葉で書く形式であることに合わせた判断（バンドが灯体図を描かないことを調査で確かめたわけではない）。
3. ステージ図・チャンネル表・機材表は同じデータから作り、チャンネル番号を自動で揃える。番号を一致させることが推奨されているため。

## 2. 帳票フォーマット決定案

全帳票共通のヘッダー: バンド名 / 公演名 / 会場 / 日付 / 出番（何組目か）/ 持ち時間 / 連絡先（任意）。

### 帳票A: セットリスト（A4縦）

**A-1 演者用（ステージの足元・モニター前に貼る）**
```
┌──────────────────────────┐
│ BAND NAME     2026.11.14 @VENUE │
├──────────────────────────┤
│ SE  Opening SE                  │
│ 1   曲名（特大）          ♩=168 │
│     ▸ 注釈（小）: カウント4つ    │
│ 2   曲名                  ♩=120 │
│ ── MC ──（メモ: 告知）           │
│ 3   曲名  ⟶ 曲間なしで4へ        │
│ 4   曲名                         │
│ ═ EN ═                          │
│ 5   曲名                         │
└──────────────────────────┘
```
- 曲名は行数に合わせて自動で縮める（目安: 10曲で1行28〜40pt）
- 表示切替: BPM / キー / 注釈 / 曲番号
- 太字・反転モード（暗いステージでも読めるように）

**A-2 スタッフ用（PA・照明・舞台監督向けの表）**

| # | 種別 | 曲名 | 原曲 | BPM | Key | 尺 | つなぎ | 注釈 |
|---|------|------|------|-----|-----|----|--------|------|
| SE | SE | Opening | — | — | — | 1:30 | F.O.で1曲目 | 音源はUSBで持参 |
| 1 | 曲 | 曲名 | オリジナル | 168 | E | 4:10 | 曲間なし | Gtソロ: 上手 |
| — | MC | MC① | — | — | — | 2:00 | — | 告知あり |

- 種別: `曲` / `MC` / `SE` / `転換・チューニング` / `アンコール区切り` / `自由メモ`
- 合計時間を自動で出し、持ち時間を超えたら警告する（印刷物には載せない）

### 帳票B: ステージ図＋機材表（A4横。1枚で収まらないときは2枚に分ける）

**B-1 ステージ図（上半分）**
- 上から見た図。客席を下に置くのは国内でも海外でも一般的な描き方
- 「上手・下手」を明記する。上手は客席から見て右側。初心者がよく間違えるので図の両端にラベルを固定で描く
- 置けるパーツ（SVGアイコン）: ボーカル / ギター / ベース / キーボード / ドラムセット / ギターアンプ / ベースアンプ / マイクスタンド（ストレート・ブーム）/ モニタースピーカー / DI / エフェクターボード / 電源（コンセント数）/ ドラム台 / 譜面台 / 椅子 / 自由テキスト
- 各パーツに付けるもの: ラベル（例: 「Gt.Vo 山田」）、そのパーツからの入力を表すチャンネル番号の丸印（チャンネル表と自動で連動）
- グリッドに吸着させ、回転は90°刻み

**B-2 チャンネル表（下半分の左）**

| CH | 楽器 | マイク/DI | スタンド | 48V | 持込 | 備考 |
|----|------|-----------|----------|-----|------|------|
| 1 | Kick | 会場 | — | | | |
| 9 | Ba | DI | — | | ○ | ラインのみ |
| 12 | Vo | SM58 | ブーム | | ○ | 持込マイク |

- ステージ図のパーツから自動で作り、行の並べ替えでCH番号を振り直す
- ドラムのプリセット: 最小（Kick / Snare / OH）と標準（Kick / Snare / HH / Tom1 / Tom2 / FTom / OH L / OH R）

**B-3 機材表（下半分の右）**

| パート | 担当 | 機材 | 持込/借用 | 備考 |
|--------|------|------|-----------|------|
| Gt | 山田 | Marshall JCM2000 | 借用(会場) | ヘッドのみ持込 |
| Dr | 佐藤 | スネア, ペダル, シンバル | 持込 | キットは借用 |

- 項目の末尾に「モニターの返し要望」をメンバーごとに1行
- 電源が必要な機材の数を集計して表示する

### 帳票C: 音響・照明シート（A4横）

ヘッダーの下に全般要望の欄: 照明（例: 全体を暗め、ストロボNG）/ 音響（外音の方針、返しの全般）/ SE・同期・クリックの扱い（再生機器・出力の方法）。

曲ごとの表（セットリストの行と連動。MC・SEの行もそのまま入る）:

| # | 曲名 | 照明の色 | 雰囲気 | 明るさ | 動き | きっかけ・特記 | 音響（コーラス/ソロ/効果） |
|---|------|----------|--------|--------|------|----------------|----------------------------|
| 1 | 曲名 | ■赤 ■白 | 激しく | 明 | 速い | 頭のキメで全灯 / Gtソロで上手にスポット | Cho: Gt.Vo, Ba / Gtソロ: 上手 |
| — | MC | 地明かり | — | 中 | なし | | MCマイク: Vo |
| 3 | 曲名 | ■青 | しっとり | 暗 | なし | Vo1人で始まるので板付き暗転 | Voにリバーブ深め |

- 照明の色はパレット（赤・橙・黄・緑・青・紫・白・お任せ）から最大3色。印刷時は色のマスと文字の両方で出す（白黒印刷でも読めるように）
- 明るさ: 暗 / 中 / 明。動き: なし / ゆっくり / 速い / 曲に合わせる
- 「きっかけ」は自由文。入力候補として「暗転スタート」「頭のキメで」「サビで」「ソロでスポット」「エンディングで暗転」を出す

## 3. 横断の決定事項

| 項目 | 決定 | 理由 |
|------|------|------|
| データ | 1公演 = 1つのJSON（メンバー・曲・ステージのパーツ・機材・全般要望）。帳票はすべてここから作る | チャンネル番号と曲順を帳票の間で揃えるため |
| 保存 | localStorageに自動保存し、JSONファイルで書き出し・読み込み | サーバーを持たないため |
| 印刷 | `@page { size: A4 portrait/landscape; margin: 10mm }`、帳票ごとに `break-before: page` | ブラウザの印刷からPDF保存もできる |
| 図 | SVGで描く（mm単位のviewBox） | 印刷しても荒れず、拡大縮小しても線幅が保てる |
| 白黒印刷 | 色だけに意味を持たせない（文字・模様を添える） | 会場のプリンタはモノクロが多い |
| 言語 | 項目名は日本語。英語表記に切り替えられるようにしておく | 海外アーティストや外国人スタッフ向け |

## 4. 決めてほしいこと（未定のときは右の方針で進める）
- 帳票Bを1枚にするか、2枚（ステージ図 / 表）にするか → 既定は1枚。CHが16を超えたら自動で2枚に分ける
- 照明に「灯体の指定（スポット・ムービング等）」の欄を設けるか → 既定は設けない。きっかけ・特記の自由文で書く
